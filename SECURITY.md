# Security Policy

## Supported Versions

Only the latest stable release is supported with security updates. Older versions are not maintained.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues or discussions.

For now, please report vulnerabilities via email:

`sigil-cli@googlegroups.com`

I will acknowledge your report as soon as possible (usually within 48 hours) and work on a fix.
If you have a patch, feel free to include it, but keep the initial report brief.

Thank you for helping keep this project safe.
